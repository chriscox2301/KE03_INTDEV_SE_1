# KE03_INTDEV_SE_1_Base

Dit project is een startpunt voor de eerste inleveropdracht voor alle studenten die het keuzevak Interface Development hebben gekozen. Dit project is een Razor Pages gebaseerde web applicatie inclusief een data access layer.

# Functionele Requirements

| Code | Requirement                                                            | MoSCoW      |
| ---- | ---------------------------------------------------------------------- | ----------- |
| KR1  | Klant kan een of meerdere producten selecteren om te bestellen         | Must Have   |
| KR2  | Klant moet zien wat hij eerder bestelt heeft                           | Must Have   |
| KR3  | Klant moet zien wat de producten kosten                                | Should have |
| KR4  | Klant wilt weten of de bestelling succesvol is                         | Cloud have  |
| KR5  | Klant wilt een product meerdere keren bestellen                        | Must Have   |
| KR6  | Klant kan een lijst van beschikbare producten inzien.                  | Must have   |
| KR7  | Klant kan per product een gewenste hoeveelheid opgeven<br>             | Must have   |
| KR8  | Klant kan per bestelling in de orderhistorie de besteldetails bekijken | Must have   |

# Non-Functionele Requirements
| Code | Requirement                                                                           | MoSCoW    |
| ---- | ------------------------------------------------------------------------------------- | --------- |
| NKR1 | De applicatie maakt gebruik van de meegeleverde data access layer                     | Must have |
| NKR2 | De UI past zich aan aan verschillende schermformaten (responsive design)              | Must have |
| NKR3 | De applicatie past HCI-ontwerpprincipes toe                                           | Must have |
| NKR4 | De broncode is via meerdere commits beschikbaar op een persoonlijke GitHub-repository | Must have |
| NKR5 | De applicatie maakt gebruikt van meerdere HTML-elementen en toegepaste CSS-stijlen    | Must have |
# Randvoorwaarde
- De applicatie is gebouwd met ASP.NET Core Razor Pages.

# Usecases 
1. Klant plaatst een bestelling
2. Klant bekijkt orderhistorie
